📊 WHAT EACH FILE CONTAINS
═══════════════════════════════════════════════════════════════════════════

merged_standards.csv
  Format: Spreadsheet (Excel compatible)
  Content: 197 rows × 24 columns
  Columns: designation, title, year, division, committee, part,
           section, is_current, superseded_by, archive_url, text_path, etc.
  Size: 132 KB

merged_standards.json
  Format: JSON array
  Content: All 197 standards
  Structure: { "id": "...", "designation": "...", "title": "...", ... }
  Size: 241 KB

chunked_documents.jsonl
  Format: Line-delimited JSON
  Content: 9,043 text chunks (one per line)
  Each: { "standard_id": "...", "chunk": "...", "chunk_index": 0, ... }
  Size: 9.3 MB
  Use: Embed each chunk with your AI model

qa_pairs.jsonl
  Format: Line-delimited JSON
  Content: 985 question-answer pairs
  Each: { "question": "...", "answer": "...", "metadata": {...} }
  Size: 418 KB
  Use: Train or fine-tune your language model

archive/text/*.txt
  Format: Plain text files
  Content: Full OCR'd standard documents
  Files: 197 (one per standard)
  Example names: gov.in.is.1.1968.txt, gov.in.is.10.2.2013.txt
  Size: ~2 MB total

semantic/*.json
  Format: JSON files
  Content: 
    - category_hierarchy.json: 14 domains, 40+ committees
    - cross_references.json: 17 version chains
    - temporal_index.json: Year-by-year organization
    - search_facets.json: Filtering dimensions
    - domain_ontology.json: Domain structure
  Size: 0.15 MB total
