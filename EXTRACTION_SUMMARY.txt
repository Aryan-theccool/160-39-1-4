DATA FIELDS IN CSV/JSON
================================================================================

• canonical         - Unique key (e.g., "IS|1|None|None|1968|None")
• designation       - Standard reference (e.g., "IS 1:1968")
• title             - Full standard name
• year              - Publication year
• prefix            - Usually "IS"
• number            - Standard number
• part              - Part number (if multi-part, else empty)
• section           - Section number (if applicable)
• division          - Broad domain (e.g., "Textiles", "Civil Engineering")
• section_name      - Specific category
• committee         - Technical committee code
• status            - Usually "published"
• is_current        - TRUE if latest edition, FALSE if superseded
• superseded_by     - Name of newer edition (if applicable)
• has_full_text     - TRUE/FALSE whether OCR text available
• sources           - Where data came from (e.g., ["ARCHIVE_ORG"])
• archive_identifier- Archive.org item ID
• archive_url       - Link to source document
• license_url       - CC0 license
• text_path         - Path to OCR text file


SEARCH CAPABILITY
================================================================================

The standards are fully indexed and searchable.

Command: python -m bis_pipeline query "search terms"

Examples that work:
  python -m bis_pipeline query "cement"
  python -m bis_pipeline query "drinking water"
  python -m bis_pipeline query "electrical safety"
  python -m bis_pipeline query "reinforced concrete"

Search Type: TF-IDF lexical matching
- Searches titles, metadata, and full OCR text
- Matches keywords (not semantic meaning)
